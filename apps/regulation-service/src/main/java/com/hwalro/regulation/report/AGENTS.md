# 보고서 도메인 지침

- 보고서는 작성·수정까지만 담당하며, 결재·승인 상태나 워크플로를 추가하지 않는다.
- AI는 시뮬레이션 엔진이 계산한 공식 지표의 해석·요약·초안 작성만 한다. AI 생성값을 공식 안전 지표로 저장하거나 표시하지 않는다.
- 작성자 ID는 auth-service 소유 외부 식별자다. 작성자 정보 조회 실패가 보고서 자체의 조회를 불필요하게 실패시키지 않도록 기존 실패 처리 계약을 유지한다.
- 상태값 변경 시 `ReportStatus`, DB CHECK 제약, mapper 조건, API·화면 표시의 계약을 함께 확인한다.
