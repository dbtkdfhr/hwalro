# Simulation DB 지침

- 이 디렉터리는 simulation-service 전용 초기 스키마를 관리한다.
- 도면 버전, 시뮬레이션, 결과, 지표, 병목, 개선안의 FK·복합 FK·삭제 정책과 생성 순서를 유지한다.
- 공식 안전 지표는 엔진 결과로만 저장하며 AI 생성값을 공식 지표 컬럼에 저장하지 않는다.
- JSON 결과 구조 변경 시 엔진 출력·mapper·API·프론트엔드 소비부의 호환성을 확인한다.
- DDL 변경 최종 응답에는 변경 테이블과 직접 관계 테이블을 포함한 Mermaid `erDiagram` 코드 및 엔진·mapper·API 영향 요약을 제공한다.
