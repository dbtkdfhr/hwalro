# 도면 샘플 리소스 지침

- 이 디렉터리의 도면은 개발·테스트용 자산이며 운영 데이터로 취급하지 않는다.
- 좌표 포맷·단위·도형 의미를 변경할 때 drawing DTO, mapper, 서비스 및 프론트엔드 소비부를 함께 확인한다.
- 실제 사용자 도면이나 민감한 현장 정보를 샘플로 추가하지 않는다.
- 기본 도면을 새로 내보낼 때는 번호를 올린 새 파일을 만들고 `DefaultDrawingData`가 그 파일을 읽게 바꾼다. 옛 파일은 되돌릴 일에 대비해 남겨 둔다.
- 구역의 소속과 기본 비상구는 ID가 아니라 **배열 인덱스**로 적는다. 도면을 만들 때 요소가 새 ID를 받기 때문이다.
  인덱스는 각 배열이 `display_order ASC, id ASC` 순서라는 전제 위에 있다 — 배열 순서를 손으로 바꾸면 소속이
  조용히 엉뚱한 요소에 붙는다. 손으로 고치지 말고 `scripts/export-default-drawing.mjs`로 다시 내보내라.
